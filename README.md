# sentinelle-zero-data

Données publiées par l'app personnelle **Sentinelle Zéro** : déclarations officielles issues de
SEC EDGAR (Form 4, Form 13F) et du Clerk of the U.S. House of Representatives (PTR).

- Site (API statique JSON) : branche `gh-pages`, servie par GitHub Pages → `v1/meta.json`.
- Générées par le workflow `ingest-and-publish` (ce dépôt). Le code du pipeline est privé.
- Chaque ligne renvoie au document officiel ; en cas de divergence, le document officiel fait foi.
- Ce n'est pas un conseil en investissement.

**Données du Congrès :** en application de 5 U.S.C. §13107(c), il est illégal d'obtenir ou d'utiliser
ces déclarations (a) à des fins illégales, (b) à des fins commerciales autres que celles des médias
d'information, (c) pour établir ou évaluer la solvabilité d'une personne, ou (d) pour solliciter des fonds.
